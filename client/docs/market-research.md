# DayLog 시장조사 및 기능 전략

## 1. 조사 배경

DayLog는 "할일 관리 + 일일 회고"를 결합한 웹 서비스입니다.
기획 단계에서 기존 서비스들의 기능을 분석하고, DayLog만의 차별점과 추가 기능 전략을 수립했습니다.

---

## 2. 경쟁 서비스 분석

### 조사 대상 (6개 서비스)

#### Daylio (기분 트래커 + 마이크로 저널)
- **핵심 기능**: 이모지 기반 기분 트래킹, 활동 기록, 통계/차트, Year in Pixels
- **강점**: 2탭으로 기록 완료, 극도로 낮은 진입장벽, 기분-활동 상관관계 분석
- **약점**: 할일 관리 기능 없음, 모바일 앱만 지원 (웹 버전 없음)
- **수익 모델**: 프리미엄 구독 ($4.99/월, $35.99/년)

#### Habitica (게이미피케이션 할일 관리)
- **핵심 기능**: RPG 스타일 캐릭터, XP/레벨, 파티 퀘스트, 습관 트래커
- **강점**: 강력한 게이미피케이션, 커뮤니티 챌린지, 시각적 보상 체계
- **약점**: 회고/일기 기능 없음, 과도한 게임 요소로 복잡, UI가 구식
- **수익 모델**: 인앱 구독 + 보석 구매

#### Todoist (할일 관리)
- **핵심 기능**: 할일 CRUD, 카르마(XP) 시스템, 스트릭, 프로젝트/라벨 분류
- **강점**: 깔끔한 UI, 크로스 플랫폼, 자연어 입력, 카르마 레벨링
- **약점**: 회고/일기 기능 없음, 기분 트래킹 없음
- **수익 모델**: 프리미엄 구독 ($4/월)

#### Day One (프리미엄 저널)
- **핵심 기능**: 리치 텍스트 일기, 사진/위치/날씨 자동 기록, "1년 전 오늘" 알림
- **강점**: 아름다운 UI, 멀티미디어 지원, E2E 암호화, "On This Day" 기능
- **약점**: 할일 관리 없음, 유료 구독 필수, 모바일/Mac만 지원
- **수익 모델**: 프리미엄 구독 ($2.92/월)

#### Reflection (AI 저널링 코치)
- **핵심 기능**: AI 기반 저널 프롬프트, 패턴 인식, 감정 분석, 가이드 저널링
- **강점**: AI가 개인화된 질문 제공, 주간 인사이트 리포트, 무료 버전 넉넉
- **약점**: 할일 관리 없음, AI에 의존적, 자유 작성 제한
- **수익 모델**: 프리미엄 구독

#### BeeDone (게이미피케이션 + AI 코치)
- **핵심 기능**: XP/레벨, AI 코치(3종), 스트릭 아트, 딥워크 타이머, 태스크 룰렛
- **강점**: 다층 게이미피케이션, AI 코치 선택, 스트릭 유지 시 AI 아트 생성
- **약점**: 회고 기능 약함, 구독 비용 높음 ($8/월)
- **수익 모델**: 프리미엄 구독

## 4. DayLog 핵심 차별점

### "할일 완료 → 회고 자동 연동"은 시장에 없다

조사한 6개 서비스 중 **할일 관리와 회고를 동시에 제공하면서 데이터를 연동하는 서비스는 없습니다.**

- Todoist, Habitica: 할일만 (회고 없음)
- Daylio, Day One, Reflection: 회고/일기만 (할일 없음)
- 사용자는 할일 앱 + 일기 앱을 따로 써야 하는 상황

DayLog는 이 두 기능을 하나로 통합하고, 완료한 할일이 회고 화면에 자동으로 표시되어 "오늘 뭘 했는지" 되돌아보는 과정을 자연스럽게 만듭니다.

## 5. 추가 기능 전략

경쟁 서비스에서 검증된 기능들을 DayLog에 맞게 가져옵니다.

### 1순위: 기본 확장 (3주차)

#### 기분 트래킹
- **참고**: Daylio의 5단계 이모지 시스템
- **적용**: 회고 작성 시 오늘 기분을 이모지로 선택
- **구현**: Reflection 스키마에 `mood` 필드 추가 (1~5 정수)
- **이유**: 구현 난이도 낮음, 사용자 데이터 풍부해짐

#### 연속 기록 스트릭
- **참고**: Daylio, Todoist의 스트릭 시스템
- **적용**: 매일 할일 완료 + 회고 작성 시 스트릭 카운트 증가
- **구현**: 별도 Streak 컬렉션 또는 User 모델에 streak 필드
- **이유**: 습관 형성 유도, 재방문율 증가

### 2순위: 차별화 강화 (4주차)

#### XP + 레벨 시스템
- **참고**: Habitica의 RPG 시스템, Todoist의 카르마
- **적용**: 할일 완료 시 +10 XP, 회고 작성 시 +20 XP, 스트릭 보너스 XP
- **레벨 설계**:
  - Lv.1 입문자 (0 XP)
  - Lv.2 기록러 (100 XP)
  - Lv.3 실천가 (300 XP)
  - Lv.4 꾸준러 (600 XP)
  - Lv.5 달인 (1000 XP)
- **이유**: 면접에서 "게이미피케이션 설계" 어필, 프론트엔드 상태관리 실력 입증

#### Year in Pixels
- **참고**: Daylio의 Year in Pixels
- **적용**: 365일 캘린더에 기분 색상으로 1년 감정 흐름 시각화
- **구현**: Canvas 또는 CSS Grid로 365개 셀 렌더링
- **이유**: 시각화 구현 능력 어필, 포트폴리오 스크린샷에 임팩트

#### 기분-활동 상관관계 분석
- **참고**: Daylio의 통계 기능
- **적용**: "운동한 날 기분 평균 4.2 vs 안 한 날 3.1" 같은 인사이트
- **구현**: MongoDB aggregation으로 카테고리별 기분 평균 계산
- **이유**: 데이터 처리 능력 어필

### 3순위: 와우 기능 (4주차 이후, 선택)

#### AI 주간 코치 (Ollama)
- **참고**: Reflection의 AI 인사이트
- **적용**: 주간 회고 자동 요약 + 생산성 패턴 분석
- **이유**: AI 활용 경험 어필

#### 업적 배지 시스템
- **참고**: Habitica의 업적
- **적용**: "첫 회고 작성", "7일 스트릭", "100개 할일 완료" 등
- **이유**: 컬렉션 요소로 재미 추가

#### 타임캡슐 (1년 전 오늘)
- **참고**: Day One의 "On This Day", Penzu의 타임캡슐
- **적용**: 과거 회고를 "1년 전 오늘" 알림으로 다시 보여줌
- **이유**: 장기 사용 유도, 성장 실감

## 7. 결론

DayLog의 경쟁 전략은 다음과 같습니다:

1. **핵심 차별점 사수**: 할일 ↔ 회고 연동은 시장에 없는 기능. 이것을 중심으로 서비스 정체성 구축
2. **검증된 기능 차용**: Daylio(기분 트래킹), Habitica(게이미피케이션), Todoist(스트릭)에서 검증된 기능을 DayLog 맥락에 맞게 적용
3. **AI로 차별화 강화**: Ollama를 활용한 무료 AI 기능으로 유료 서비스(Reflection)와 차별화
4. **웹 기반 무료 서비스**: 대부분의 경쟁 서비스가 모바일 앱 중심인 반면, DayLog는 웹 기반 무료 서비스로 접근성 확보
